# 便捷游戏台 · 需求文档（PRD）

> 版本：v1.0　最后更新：2026-10-25
> 本文档为开发依据，已与需求提出方确认全部关键歧义点。

---

## 1. 项目定位

一个纯前端、零构建、零依赖的**便捷游戏辅助网页**：玩家在游戏前/游戏中填写"行动组合"，配合计时器、定时循环提醒、图片速查区、随机骰子工具使用。

- 部署/获取方式：提交 GitHub 静态仓库，其他设备下载后**双击 `index.html` 即可运行**（也可用任意静态服务器打开）。
- 不包含任何服务端、API Key、账号体系；所有数据仅存于浏览器 `localStorage`，**无敏感信息**。

## 2. 技术选型（自行决定）

| 项目 | 选型 | 理由 |
|---|---|---|
| 形态 | 纯 HTML + CSS + 原生 JS（无框架、无打包） | 双击即用、GitHub 下载零配置 |
| 脚本加载 | 普通 `<script>` 标签（非 ES Module） | 保证 `file://` 协议下也能运行 |
| 生成图片 | Canvas 2D 自绘并导出 PNG DataURL | 不引入 html2canvas 等外部库 |
| 灯箱 | 自研轻量灯箱（缩放/拖拽/下载/关闭） | 不依赖 CDN，离线可用 |
| 提示音 | WebAudio 振荡器短蜂鸣 | 无音频资源文件 |
| 真随机 | `crypto.getRandomValues()` + 拒绝采样 | 消除取模偏差，真随机 |
| 数据存储 | `localStorage` | 浏览器端持久化 |

## 3. 整体布局

三栏布局（左 / 中 / 右），每栏上中下三个区域，每个区域为一个**新拟态圆角卡片**（外凸大圆角、双向阴影）。

```
┌──────────┬──────────┬──────────┐
│ 左：筛选  │ 中：计时  │ 右：图片  │
│ 左：组合  │ 中：提醒  │ 右：笔记  │
│ 左：按钮  │ 中：结束  │ 右：骰子  │
└──────────┴──────────┴──────────┘
```

设计语言：新拟态（Neumorphism）
- 底色：温润灰 `#F0F0F0`；卡片 `#FFFFFF`；
- 阴影：外阴影用暖灰投影 `#d1d1d1`，内阴影用冷白高光 `#ffffff`，按压态切换为内凹双重阴影；
- 强调色：活力蓝 `#00ABFF`、活力粉 `#FF99CC`；
- 交互动画：按钮悬停微浮起、按压内凹、弹性过渡（`cubic-bezier`），提醒行闪烁动画。

## 4. 左栏

### 4.1 上方 · 筛选区
- 一个**关键词输入框** + 一个**查询按钮**。
- 多条件：输入框内以空格分隔多个关键词，为 **AND 关系**（全部命中才显示）。
- 点击"查询"：左侧组合列表仅保留命中的组合（未命中的折叠隐藏）；关键词清空后再次点击"查询"恢复全部。
- 筛选不修改任何已填内容，只控制显隐，方便后续继续编辑。

### 4.2 中间 · 组合填写区（最多 20 个，有序列表全部显示）
每个组合的固定结构（**8 个文本输入位 + 6 个连接器下拉框**，第 4 位与第 5 位之间固定文字"的情况下"）：

```
[输入1] [▾和] [输入2] [▾和] [输入3] [▾和] [输入4] 的情况下
[输入5] [▾和] [输入6] [▾和] [输入7] [▾和] [输入8]
```

- 下拉框四选一：**和 / 或 / 做 / 不做**，默认值"和"。
- 组合以"第 N 组合"标题行 + 折叠箭头展示。
- **自动折叠规则（保存时执行）**：某组合 8 个输入全为空且 6 个下拉全部保持默认值"和" → 判定为未使用，自动折叠为标题行；有任意内容则展开。
- 已折叠的组合玩家可手动点开编辑。

### 4.3 下方 · 按钮区：保存 / 重置 / 显示
- **保存**：仅做格式规整（去除首尾空格、压缩连续空白），输入框与下拉框 UI 完全不变，方便增量修改；覆盖式保存到 `localStorage`；空输入保存后即为空。可多次保存。
- **重置**：20 个组合全部恢复默认（输入清空、下拉回到"和"、全部展开），并清除存储。
- **显示**：将**已保存的、有内容的组合**用 Canvas 生成一张 PNG 图片，自动载入右侧上方图片区。若尚无已保存内容 → Toast 提醒"请先保存后再生成显示"。

## 5. 中栏

### 5.1 上方 · 综合区
- **游戏时长**：大号数字 `HH:MM:SS`。未开始前，该位置显示红色大字提示"请先'开始'计时"，点击"开始"后提示消失、开始走时。
- **定时循环提醒事件设置**：每行 = `组合序号(1~20 下拉)` + `间隔分钟(数字输入)` + `添加`按钮；最多 20 个事件，可删除。
- 按钮行：**开始 / 暂停 / 继续 / 重置（小按钮）**。
  - 开始：启动计时，红字提示消失、时间显示。
  - 暂停：仅计时中有效，否则 Toast 提醒"请先开始计时"。
  - 继续：仅暂停中有效、恢复走时；**待开始态（含重置后）点击继续无效并提醒，必须点"开始"启动**。
  - 重置（小号）：弹确认框——选"是"则**计时归零并停表**，回到待开始态（红字"请先开始计时"），需再点"开始/继续"才重新走时；选"否"/关闭则计时不停、继续走。

### 5.2 中间 · 提醒列表面板
- 有序列出全部提醒事件：组合序号、该组合的内容快照（取已保存内容）、**距下次提醒剩余 mm:ss**。
- 到点行为（已确认）：**对应行高亮闪烁 + WebAudio 短促蜂鸣**，随后倒计时自动重置进入下一轮；面板提供静音开关。

### 5.3 下方 · 结束区
- **"结束"大按钮**：点击后所有计时暂停、事件倒计时冻结，页面进入静止态（所有操作控件禁用）。
- 旁边新增 **"重新开始"按钮**（初始禁用）：仅在"结束"后可点击。点击后：计时归零、解冻页面、提醒事件倒计时重置、**保留已保存的组合、清空右侧笔记**。

## 6. 右栏

### 6.1 上方 · 图片区（默认空）
- 点击空区域 → 调起本地文件选择（`image/*`，png/jpg/gif/webp/svg/bmp 均可），选中即载入显示。
- 由左栏"显示"按钮生成的图片也自动载入此处。
- **已有图片时再点击区域** → 进入灯箱：图片全屏居中，支持滚轮/按钮放大、拖拽平移、下载 PNG、关闭。

### 6.2 中间 · 笔记区
- 有序列表，每行一个文本输入框，默认 4 条，"添加条目"按钮可增加（无硬性上限），可删除单行。
- 数据存浏览器；"重新开始"时被清空丢弃。

### 6.3 下方 · 随机骰子区
- 默认 **2 列**骰子组，每列独立配置：
  - **位数**：该组骰子个数（1~26）；
  - **正倒序**：正序 → 标签 A、B、C…；倒序 → 从字母表末尾向前数 N 位但显示仍按正序（3 位倒序 = X、Y、Z；5 位正序 = A、B、C、D、E）；
  - **数值范围**（已确认）：玩家可选 `0~10` / `1~100` / `1~6`；
  - 每列带**折叠勾选框**，可折叠不需要的列。
- 新增 **"投掷"按钮**：对所有未折叠列用真随机（`crypto.getRandomValues` + 拒绝采样）一次性出数，显示如 `X: 73　Y: 12　Z: 95`。

## 7. 数据与边界

| 键 | 内容 |
|---|---|
| `gm.combos.v1` | 20 组合的 8 输入 + 6 下拉 |
| `gm.notes.v1` | 笔记条目数组 |
| `gm.dice.v1` | 骰子组配置（列数/位数/正倒序/范围/折叠态） |
| `gm.reminders.v1` | 提醒事件（序号 + 间隔） |

- 首次打开无任何数据，全部走默认态。
- 不收集任何用户输入到外部；README 明确告知数据仅存本机浏览器。
